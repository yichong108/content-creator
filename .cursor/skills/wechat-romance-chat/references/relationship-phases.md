# 关系六阶段 — 话题与语气参考

男生 = `outgoing`，女生 = `incoming`。以下仅为灵感，每次生成应换人设与具体台词，避免复读本表。

---

## 1. 陌生人（10–15%）

**情境**：刚加好友、群聊认识、朋友介绍、活动扫码等。

**男生语气**：礼貌、略拘谨、不会太长  
**女生语气**：友好、带一点好奇

**典型话题**：怎么称呼、哪里人、做什么的、周末干嘛、表情包式「哈哈」

**示例方向**（勿原样复制）：
- outgoing: 「通过一下哈，我是上次活动签到的」
- incoming: 「好呀，我是 xxx」
- system: `以上是打招呼的消息`

**时间**：timestamp 间隔数小时到一两天

---

## 2. 破冰熟悉（15–20%）

**情境**：找到共同爱好，开始主动找对方聊。

**语气**：放松、会开玩笑、偶尔连发

**典型话题**：剧/游戏/猫/吃的、吐槽工作、分享链接、「你也看这个？」

**节奏**：回复变快；开始出现 evening 深夜聊

---

## 3. 暧昧试探（15–20%）

**情境**：不确定是不是喜欢，用玩笑试探。

**男生**：多主动发起、关心细节、半开玩笑  
**女生**：可能欲擒故纵、发表情文字、问「你怎么还没睡」

**典型话题**：单独约饭/看展、「你怎么每天都这么晚」、节日、送东西、「别人以为你是我女朋友哈哈」

**system 可选用**：`"豆包" 撤回了一条消息`（暗示删了太直白的句子）

**注意**：暧昧期不要直接叫「老婆/老公」，除非后面有明确表白段

---

## 4. 确认恋爱（20–25%）

**情境**：一方表白或双方默认在一起。

**语气**：甜但别太文艺；日常报备、撒娇、计划周末

**典型话题**：昵称（宝贝/名字叠字）、早安晚安、吃了吗、想你了、一起旅行、见朋友、情侣头像

**连发示例模式**（参考 page.tsx 现有风格）：
- 多条 outgoing 关心式追问（吃饭了吗、到家了吗）— 适合热恋期日常，不宜放在陌生人段

**timestamp**：可标注「在一起第 N 天」类文案，或节日名

---

## 5. 平淡与裂痕（15–20%）

**情境**：激情减退 + 具体矛盾（忙、异地、误会、消费观、前任、边界感）。

**语气变化**：
- 回复变短、变慢
- 「嗯」「哦」增多
- 一方解释，一方「算了」
- 可能出现已读不回后隔很久才回

**典型冲突点**（选 1–2 个写深，不要全堆）：
- 忘记重要日子
- 和异性朋友吃饭没提前说
- 工作太忙连续几天敷衍
- 「你根本不懂我」类情绪爆发

**不要**：毫无铺垫下一句「我们分手吧」

---

## 6. 分手收尾（10–15%）

**情境**：冷静谈分、或一方决绝、或慢慢冷处理结束。

**常见走向**（选一种，保持一致）：
- **A. 理性告别**：双方承认不合适，互祝安好
- **B. 一方退出**：incoming 或 outgoing 最后几条是单方面告别，另一方简短回应
- **C. 冷处理**：越来越短，最后停在某一方 unanswered

**结尾特征**：
- 称呼回到全名或不再用昵称
- 最后 1–3 条不宜再开新话题
- 可选 system：无强制；一般不写「已拉黑」（除非 UI 支持）

**之后状态**：若用户要改 header 标题，分手后可建议改为全名或「。」而非「豆包」

---

## 情感曲线示意

```
亲密度
  ▲
  │        ╭──恋爱高峰──╮
  │       ╱              ╲
  │      ╱ 暧昧            ╲ 裂痕
  │     ╱                    ╲
  │────破冰                      ────分手
  └──────────────────────────────────► 时间
   陌生人
```

生成时在「高峰」与「裂痕」之间要有过渡段（例如几次小吵和好），长线更可信。
